Portfólio pessoal de Jônatas José, desenvolvedor Full Stack Júnior. Reúne apresentação profissional, áreas de estudo e links de contato e currículo.

## Recursos

- Apresentação e seção sobre a trajetória de desenvolvimento.
- Tecnologias organizadas em front-end, back-end e boas práticas.

## Tecnologias

O site é estático, construído com **HTML5 e CSS3**, e utiliza fontes do Google Fonts. Não exige instalação de dependências nem etapa de compilação.

As tecnologias citadas no conteúdo do portfólio representam áreas de estudo e atuação; a implementação deste site usa HTML e CSS.

## Executar localmente

Clone o repositório:

```sh
git clone https://github.com/Kalebreus/portifolio.git
cd portifolio
```

Abra `index.html` no navegador ou use a extensão Live Server do VS Code.

Se tiver Python 3 instalado, também pode iniciar um servidor local:

```sh
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## Estrutura

```text
portifolio/
├── .github/          # Configurações do GitHub
├── index.html        # Conteúdo e estrutura da página
├── src/
│   ├── css/          # Estilos e reset
│   └── img/          # Imagens do portfólio
└── README.md
```

## Personalização

- Edite textos, navegação e links em `index.html`.
- Ajuste a identidade visual em `src/css/style.css`.
- Mantenha os arquivos de imagem em `src/img/` e atualize suas referências no HTML.
